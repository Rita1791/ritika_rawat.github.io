# Upload and deploy on GitHub

Repository: https://github.com/Rita1791/ritika_rawat.github.io

1. Extract the ZIP on your computer.
2. Open the extracted folder named `Ritika_Rawat_GitHub_Portfolio`.
3. On GitHub, open the repository and choose **Add file → Upload files**.
4. Drag all items from inside the extracted folder into the repository: `index.html`, `assets`, `README.md`, `UPLOAD_GUIDE.md`, `robots.txt`, `LICENSE`, and `.nojekyll`.
5. Upload the contents, not the ZIP and not the outer folder.
6. Commit to the `main` branch.
7. Open **Settings → Pages**.
8. Set **Source** to **Deploy from a branch**, **Branch** to `main`, and **Folder** to `/(root)`.
9. Save and wait for the Pages deployment to complete.
10. Open https://rita1791.github.io/ritika_rawat.github.io/

## Add your photo later

Upload it to `assets/img/ritika-headshot.jpg` with that exact lowercase filename. No code change is required.

## Important replacement step

Delete or overwrite the old repository files when GitHub asks. The old page refers to CV and benchmark files that were never uploaded; this package contains both missing assets and fixes the download links.
