# Manual GitHub Pages deployment

1. Open `Rita1791/ritika_rawat.github.io` on GitHub.
2. Delete or replace any old website files so the repository root contains this package's `index.html`.
3. Select **Add file → Upload files**.
4. Drag the **contents** of this package into the repository. Do not upload the outer package folder.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select `main` and `/(root)`, then click **Save**.
9. Open **Actions** and wait for **pages build and deployment** to finish.
10. Visit `https://rita1791.github.io/ritika_rawat.github.io/`.

## Add the profile photograph

Upload a professional square image as `images/ritika-photo.jpg`. Keep that exact filename and path. The `RR` monogram remains visible when the image is missing.

## Later updates

Replace the relevant file and commit again. GitHub Pages redeploys automatically from `main`.
